- [ ] `docker compose up -d --build`
- [ ] UI loads at port 5173
- [ ] Login works
- [ ] `/health` reports Prometheus connectivity
- [ ] Prometheus target is UP
- [ ] Server inventory updates
- [ ] Grafana dashboard loads
- [ ] Alert rule visible in Prometheus
- [ ] Alertmanager receives alert
- [ ] Email/webhook configured if demonstrating notifications
- [ ] Audit event recorded after login
- [ ] No real secrets committed
